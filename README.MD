# Cosmetic Inventory System — система учёта косметики

## Назначение

Cosmetic Inventory System — консольное приложение для учёта косметических
средств, контроля их количества и сроков годности.

Приложение позволяет:

* просматривать список косметических средств;
* искать средства по названию, бренду или категории;
* добавлять новые средства;
* изменять количество средства;
* удалять средства;
* сортировать средства по сроку годности;
* определять состояние срока годности и запасов;
* формировать список средств для пополнения или замены;
* просматривать сводную статистику;
* хранить данные между запусками приложения.

## Целевая аудитория

Частные пользователи, визажисты, бьюти-мастера и сотрудники салонов, которым
необходимо учитывать косметические средства, контролировать запасы и вовремя
заменять продукты с истекающим сроком годности.

## Предметная область

Основным объектом предметной области является косметическое средство. Для
каждого средства хранятся название, бренд, категория, количество и срок годности.

Идентификатор средства должен быть положительным, обязательные текстовые поля не
могут быть пустыми, а количество не может быть отрицательным. Средство требует
пополнения или замены, если осталась одна единица или запас закончился, а также
если до окончания срока годности осталось не более 30 дней.

После перехода к объектной модели приложение работает с коллекцией
`list[Product]`. Объекты хранят данные и выполняют операции, относящиеся к
конкретному средству. Функции модулей организуют работу с коллекцией объектов,
пользовательскими сценариями и внешним хранилищем.

## Основные сущности

### Product — косметическое средство

Объект `Product` представляет косметическое средство, находящееся на учёте.

Основные атрибуты:

* `id` — уникальный идентификатор средства;
* `name` — название средства;
* `brand` — бренд;
* `category` — категория;
* `quantity` — количество единиц;
* `expiry_date` — срок годности в виде объекта `date`.

Основные методы:

* `__init__()` — создание объекта и сохранение его атрибутов;
* `validate_quantity()` — проверка корректности количества;
* `get_expiry_status()` — определение состояния срока годности;
* `get_quantity_status()` — определение состояния запасов;
* `needs_restock()` — проверка необходимости пополнения или замены;
* `change_quantity()` — изменение количества средства;
* `__str__()` — строковое представление средства.

Метод `validate_quantity()` реализован с помощью декоратора `@staticmethod`.

## Основные операции

### Работа с косметическими средствами

* добавление нового средства;
* поиск по названию, бренду или категории;
* просмотр списка средств;
* сортировка по сроку годности;
* изменение количества;
* удаление средства по идентификатору.

### Контроль запасов и сроков годности

* определение состояния срока годности;
* определение состояния запасов;
* проверка необходимости пополнения или замены;
* формирование списка покупок.

### Статистика

* подсчёт количества позиций;
* подсчёт общего количества единиц;
* подсчёт категорий;
* подсчёт средств, требующих пополнения или замены.

Операции, относящиеся к одному средству, реализованы методами класса `Product`.
Добавление, поиск, сортировка, удаление и статистика реализованы обычными
функциями, работающими с коллекцией объектов.

## Хранение данных

Данные приложения хранятся в JSON-файле:

* `data/products.json`.

Для каждого средства сохраняются:

* `id` — идентификатор;
* `name` — название;
* `brand` — бренд;
* `category` — категория;
* `quantity` — количество;
* `expiry_date` — срок годности в формате `ГГГГ-ММ-ДД`.

При загрузке каждая запись JSON преобразуется в объект `Product`. При сохранении
объекты `Product` преобразуются обратно в данные JSON. Формат файла после перехода
к объектной модели не изменился.

## Назначение модулей

### `main.py`

Точка входа в приложение.

Отвечает за:

* запуск приложения;
* отображение меню;
* получение данных от пользователя;
* вывод информации о средствах;
* организацию пользовательских сценариев;
* сохранение данных перед завершением работы.

### `models/products.py`

Содержит класс `Product` и функции работы с коллекцией косметических средств.
Методы класса управляют состоянием конкретного объекта, а функции выполняют
добавление, поиск, сортировку, удаление и расчёт статистики.

### `models/__init__.py`

Предоставляет импорт класса `Product` из пакета `models`.

### `storage.py`

Отвечает за загрузку и сохранение данных.

Выполняет преобразования:

* JSON → объекты `Product`;
* объекты `Product` → JSON.

### `utils.py`

Содержит вспомогательные функции:

* `input_int()` — безопасный ввод целого числа;
* `input_date()` — безопасный ввод даты.

### `tests/`

Содержит автоматизированные тесты объектной модели, операций над коллекцией и
хранилища данных.

## Запуск приложения

Для установки зависимостей выполнить:

```text
python -m pip install -r requirements.txt
```

Для запуска приложения выполнить:

```text
python main.py
```

После запуска отображается главное меню.

## Тестирование

Для запуска автоматизированных тестов выполнить:

```text
pytest -v
```

Тесты проверяют:

* создание объекта `Product` и значения его атрибутов;
* строковое представление объекта;
* методы класса и изменение состояния объекта;
* валидацию идентификатора, обязательных полей и количества;
* добавление, поиск, сортировку, изменение и удаление средств;
* правила контроля запасов и сроков годности;
* расчёт статистики;
* загрузку объектов из JSON;
* сохранение объектов в JSON;
* обработку отсутствующих и некорректных файлов.
