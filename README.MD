# Cosmetic Inventory System

## Назначение
Приложение для учёта косметики: помогает отслеживать сроки годности, количество и категории средств, избегать просроченных продуктов и вовремя пополнять запасы.

## Целевая аудитория
- Частные пользователи с большим количеством косметических средств
- Визажисты и бьюти-мастера
- Сотрудники салонов красоты и магазинов косметики

## Предметная область
Учёт косметических средств: хранение информации о продуктах, сроках годности, категориях, брендах, количестве и статусе использования.

## Основные сущности
- Пользователь
- Косметическое средство
- Категория
- Бренд
- Срок годности
- Статус использования

## Основные функции
`main.py`
- вывод списка косметических средств
- вывод средств, которые необходимо пополнить или заменить
- вывод статистики по косметическим средствам
- вывод главного меню приложения
- обработка ввода и добавление нового косметического средства
- обработка ввода и поиск косметических средств
- обработка ввода и изменение количества средства
- обработка ввода и удаление косметического средства
- загрузка данных и запуск цикла главного меню

`products.py`
- определение статуса срока годности средства
- определение статуса наличия средства
- проверка необходимости пополнения или замены средства
- формирование строки с информацией о средстве
- добавление нового косметического средства
- перебор средств, соответствующих поисковому запросу
- поиск средств по названию, бренду или категории
- сортировка средств по сроку годности
- изменение количества косметического средства
- удаление косметического средства
- расчёт статистики по косметическим средствам

`storage.py`
- загрузка косметических средств из JSON-файла
- сохранение косметических средств в JSON-файл

`utils.py`
- обработка и проверка ввода целого числа
- обработка и проверка ввода даты

Приложение позволяет просматривать все средства, формировать список покупок,
выполнять поиск, сортировку, добавление, изменение и удаление записей через
консольное меню.

## Структура проекта
- `main.py` — точка запуска, консольное меню и функции вывода данных
- `products.py` — функции обработки данных о косметических средствах
- `storage.py` — функции загрузки и сохранения данных
- `utils.py` — функции безопасного пользовательского ввода
- `data/products.json` — данные о косметических средствах
- `tests/test_products.py` — тесты функций обработки средств
- `tests/test_storage.py` — тесты загрузки и сохранения данных
- `requirements.txt` — список инструментов разработки

## Формат данных
Данные хранятся в файле `data/products.json` в виде списка словарей. Каждая
запись содержит следующие поля:

- `id` — уникальный целочисленный идентификатор
- `name` — название косметического средства
- `brand` — бренд
- `category` — категория средства
- `quantity` — количество единиц
- `expiry_date` — срок годности в формате `ГГГГ-ММ-ДД`

Пример записи:

```json
{
    "id": 1,
    "name": "Тональный крем",
    "brand": "L'Oreal",
    "category": "Лицо",
    "quantity": 1,
    "expiry_date": "2026-12-01"
}
```
