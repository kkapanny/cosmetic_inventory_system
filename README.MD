# Cosmetic Inventory System

## Назначение
Приложение для учёта косметики: помогает отслеживать сроки годности, количество и категории средств, избегать просроченных продуктов и вовремя пополнять запасы.

## Целевая аудитория
- Частные пользователи с большим количеством косметических средств
- Визажисты и бьюти-мастера
- Сотрудники салонов красоты и магазинов косметики

## Предметная область
Учёт косметических средств: хранение информации о продуктах, сроках годности, категориях, брендах, количестве и статусе использования.

## Основные сущности
- Пользователь
- Косметическое средство
- Категория
- Бренд
- Срок годности
- Статус использования

## Основные функции
- Определение статуса срока годности средства и вывод уведомления об истечении
- Учёт количества и статуса наличия средства
- Отслеживание сроков годности и уведомления об истечении
- Проверка необходимости пополнения запаса
- Формирование информации о средстве с указанием категории, бренда и названия

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
